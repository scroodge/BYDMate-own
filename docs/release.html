VoltFlow Mate

Готовая сборка для BYD DiLink: поездки, зарядки, реальный расход, состояние батареи, плавающий виджет и автоматизация через DiPlus. Скачайте файл VoltFlow-Mate-v...apk в блоке Assets последнего релиза.

Как установить

1. Скачайте APK

Откройте последний релиз и скачайте файл VoltFlow-Mate-v...apk из блока Assets.

2. Перенесите на DiLink

Используйте USB-флешку, браузер DiLink, файловый менеджер или команду adb install.

3. Разрешите фон

После установки выключите ограничение фоновой работы: Disable background Apps = OFF.

Перед первым запуском

DiPlus обязателен

Установите DiPlus (D+), потому что VoltFlow Mate берёт live-данные машины через локальный D+ API.

ADB расширяет функции

Без ADB работают поездки, расход и виджет. Для SoH, автозарядок и автоматизации включите системные данные.

Выберите источник

Leopard 3 обычно использует BYD energydata. Song, Yuan и другие модели чаще используют DiPlus TripInfo.

Важно. Устанавливайте APK только из релизов этого репозитория или из собственной сборки. Если браузер DiLink не скачивает файл напрямую, скачайте APK на компьютер и перенесите его на USB-флешке.
