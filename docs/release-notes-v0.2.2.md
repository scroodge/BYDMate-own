# VoltFlow Mate v0.2.2

Первый публичный релиз под единым брендом VoltFlow Mate.

## Главное

- Новое имя приложения: VoltFlow Mate.
- Новый APK-файл: `VoltFlow-Mate-v0.2.2.apk`.
- Обновлены иконки приложения и release-страница.
- Подготовлена документация на русском: установка для обычного пользователя и сборка из исходников.
- Сохранён старый `applicationId` (`dev.scroodge.cloudevmate`), чтобы обновление ставилось поверх предыдущей сборки.

## Установка

1. Скачайте `VoltFlow-Mate-v0.2.2.apk` из Assets этого релиза.
2. Перенесите APK на DiLink через USB, браузер или ADB.
3. Установите APK и разрешите установку из неизвестных источников.
4. Установите DiPlus (D+), если он ещё не установлен.
5. Выключите ограничение фоновой работы для VoltFlow Mate в настройках DiLink.

## Примечания

- Для точного SoH, автоматических зарядок и автоматизации нужен ADB-доступ к DiLink.
- На эмуляторе Android можно проверить интерфейс, но реальные данные BYD/DiPlus появятся только на головном устройстве.
